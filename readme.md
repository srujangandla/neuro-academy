# 🎓 Academy Portal

A responsive academy portal built using **HTML**, **CSS**, **Bootstrap**, and **JavaScript**. The project provides a modern user interface for an online learning platform, featuring course listings, user authentication pages, and an enrollment system with a clean, responsive design.

## 📖 Description

Developed a responsive academy portal with course listings, login interface, and modern UI components using HTML, CSS, Bootstrap, and JavaScript, focusing on user experience and clean design.

---

## ✨ Features

- 📚 Responsive course catalog
- 👤 User login page
- 📝 Student registration and enrollment form
- 👨‍🎓 Student profile page
- 🌙 Theme toggle (Dark/Light mode)
- 📱 Mobile-friendly responsive design
- 🎨 Modern UI using Bootstrap
- 🧭 Simple and intuitive navigation

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
